# fuck-u-code

## 摘要

屎山代码检测器，把代码质量分析包装成 CLI、Markdown/JSON/HTML 报告、AI review 和 MCP 工具。

## 为什么是大便

它把“代码烂不烂”这种主观骂街做成了可运行的工程工具：复杂度、重复度、结构、命名等指标都能被打分，还专门输出屎山味报告。

## 证据

- GitHub README / About：[fuck-u-code](https://github.com/Done-0/fuck-u-code) 说明它用于评估 legacy-mess level，并输出代码质量报告。
- README 功能列表展示了多语言分析、Shit-Gas Index、AI code review、MCP Server 等功能。
