# BullshitGenerator

## 摘要

狗屁不通文章生成器，把给定主题扩写成一本正经但没有信息量的长文。

## 为什么是大便

它是中文 GitHub 废话文学生成的代表样本：形式像严肃作文，内容是机械堆砌的废话，节目效果来自“越正经越狗屁不通”。

## 证据

- GitHub repo：[BullshitGenerator](https://github.com/menzi11/BullshitGenerator) 是狗屁不通文章生成器的源头项目之一，GitHub stars 量级也证明其传播度。
